# Лабораторная работа: Настройка CI/CD

## Описание проекта
В данном репозитории реализован базовый процесс Continuous Integration (непрерывной интеграции) с использованием инструмента **GitHub Actions**. 

При каждом обновлении кода (`push` в репозиторий) автоматически запускается виртуальная машина на базе ОС Ubuntu, которая проверяет корректность структуры проекта и наличие необходимой документации.
